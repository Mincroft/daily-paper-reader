## 摘要
强化学习（RL）天然适用于智能体知识库问答（KBQA），其中模型必须执行可执行动作、观察知识库反馈并最终返回答案。然而，当前基于RL的KBQA系统主要优化来自最终答案的稀疏奖励，导致中间动作错误监督不足。这对于逻辑形式标注的KBQA基准尤其受限：金逻辑形式可转换为可执行动作序列，但现有流水线主要将其用于热启动数据构建，而非用于在线策略RL更新。我们提出GAPD，一种训练时的金动作策略蒸馏框架，为基于结果的RL添加密集的令牌级指导。为了将金动作与在线策略学生 rollout 对齐，GAPD使用中间锚点匹配：它将学生探索和金执行期间到达的中间实体视为状态锚点，并通过这些探索到的实体集将学生状态与金状态匹配。基于此对齐金动作的当前策略作为梯度停止教师，其令牌分布通过生成的动作令牌跨度蒸馏回普通学生策略。GAPD在WebQSP、GrailQA和GraphQ上持续超越当前最先进方法。

## Abstract
Reinforcement learning (RL) is a natural fit for agentic knowledge base question answering (KBQA), where a model must issue executable actions, observe knowledge-base feedback, and eventually return an answer. However, current RL-based KBQA systems mainly optimize sparse rewards from the final answer, leaving intermediate action errors weakly supervised. This is especially limiting for logical-form annotated KBQA benchmarks: gold logical forms can be converted into executable action sequences, but existing pipelines use them mainly for warm-start data construction rather than for on-policy RL updates. We propose GAPD, a training-time Gold-Action Policy Distillation framework that adds dense token-level guidance to outcome-based RL. To align gold actions with on-policy student rollouts, GAPD uses MID-ANCHOR MATCHING: it treats the intermediate entities reached during student exploration and gold execution as state anchors, and matches student states to gold states through these explored entity sets. The current policy conditioned on this aligned gold action serves as a stop-gradient teacher, whose token distribution is distilled back to the ordinary student policy over generated action-token spans. GAPD consistently surpasses the current state of the art on WebQSP, GrailQA, and GraphQ.

## 1. 核心问题与整体含义（研究动机和背景）

- **研究动机**：在知识库问答（KBQA）中，强化学习（RL）常用于训练智能体（agent）生成可执行的动作序列，但现有方法主要依赖最终答案的稀疏奖励（outcome reward）来优化策略，导致中间动作的错误缺乏细粒度监督。对于已标注逻辑形式的KBQA基准（如WebQSP、GrailQA、GraphQ），黄金逻辑形式可转换为可执行的动作序列，但现有流水线仅将其用于热启动数据构造（如SFT前的轨迹合成），而在在线策略RL更新时被丢弃。
- **核心问题**：如何利用黄金动作序列为RL训练提供密集的令牌级（token-level）监督信号，弥补最终奖励在中间步骤上的信用分配不足。
- **整体含义**：提出GAPD框架，通过实体锚点匹配（Entity-Anchor Matching）将学生探索状态与黄金执行状态对齐，利用对齐后的黄金动作构建条件化的自教师（self-teacher）分布，并将该分布蒸馏回学生策略，实现令牌级指导与GRPO优势的融合，显著提升KBQA性能。

## 2. 方法论：核心思想、关键技术细节、算法流程

### 核心思想
- 在基于结果的RL（如GRPO）基础上，增加来自黄金动作序列的密集令牌级指导。对于学生rollout中匹配的中间状态，将当前策略在黄金动作条件化后作为停止梯度教师，将其令牌分布蒸馏到学生策略上，同时保持原始结果奖励。

### 关键技术细节
1. **黄金动作序列解析**：将数据集的黄金逻辑形式解析为可执行动作序列，并执行得到对应的中间实体集（状态锚点）。
2. **实体锚点匹配（Entity-Anchor Matching）**：
   - 在学生rollout的当前状态 \(s_t\) 与黄金状态 \(u_m\) 之间，通过Jaccard相似度计算实体集交集：\(\text{sim}(s_t, u_m) = \frac{|E(s_t) \cap E(u_m)|}{|E(s_t) \cup E(u_m)|}\)。
   - 选择相似度最高的黄金状态进行对齐，若匹配成功，则使用该状态的下一个黄金动作作为条件。
   - 使用两个保守过滤器：跳过答案回合；若学生动作执行后达到与黄金动作相同的非空实体集，则放弃该回合的蒸馏信号（保留探索等价路径）。
3. **自教师构建**：
   - 教师侧提示：在学生上下文基础上插入对齐的黄金动作（只用于评分，不用于生成）。
   - 教师分布：\(p_{\theta}^{\text{teach}}(\cdot | \tilde{x}_t) = \text{stopgrad}(\pi_\theta(\cdot | \tilde{x}_t))\)。
   - 学生分布：\(p_{\theta}^{\text{stud}}(\cdot | x_t) = \pi_\theta(\cdot | x_t)\)。
4. **令牌级指导与GRPO融合**：
   - 对匹配的令牌位置 \(k\)，计算 \(d_{i,k} = \log p_{\theta}^{\text{teach}}(y_{i,k} | \tilde{x}_{i,k}) - \log p_{\theta}^{\text{stud}}(y_{i,k} | x_{i,k})\)，并裁剪为 \([ -c, c]\) 得到 \(A_{i,k}^{\text{gapd}}\)。
   - 融合优势：\(\hat{A}_{i,k} = A_i^{\text{grpo}} + \lambda_{\text{gapd}} A_{i,k}^{\text{gapd}}\)。
   - 采用GRPO风格的目标函数（带PPO裁剪的替代损失）更新策略。

### 算法流程（文字说明）
1. 为输入问题 \(q\) 进行学生rollout，得到轨迹 \(\tau\)，同时收集学生实体锚点状态。
2. 执行黄金动作序列，收集黄金实体锚点状态。
3. 对于每个学生回合 \(t\)：通过实体锚点匹配找到最佳黄金状态 \(u_{m^*(t)}\)；构建教师侧提示，将对应黄金动作加入上下文；将学生生成的令牌位置加入蒸馏掩码 \(I\)。
4. 从最终答案奖励计算GRPO优势。
5. 在停止梯度自教师下对学生令牌进行评分，并转换为 \(A_{i,k}^{\text{gapd}}\)。
6. 使用融合的令牌级优势，通过GRPO风格裁剪损失更新策略 \(\theta\)。

## 6. 主要结论与发现

- GAPD在三个基准上均达到当前最优：GrailQA总体F1 89.5（+3.9%相对提升），WebQSP F1 86.1（+3.2%），GraphQ F1 55.1（+2.4%）。
- 跨分割提升显著，尤其是compositional和zero-shot场景（GrailQA上compositional F1提升5.5%，zero-shot提升4.1%）。
- 实体锚点匹配是关键：无对齐（仅回合索引对齐）导致性能大幅下降（WebQSP F1从86.1降至79.3）。
- 自教师优于外部大模型教师（Qwen3-32B/14B），且开销更低。
- GAPD不仅提升准确性，还减少了平均交互次数（2.68 vs KBQA-R1的2.91 vs Claude 4.6 Sonnet的5.45），实现更高效的推理。
- 令牌级指导主要对错误分支产生强负惩罚，而非均匀作用于整个生成段。

## 7. 优点

- **方法设计亮点**：实体锚点匹配有效解决了on-policy rollout与黄金轨迹状态不对齐的问题；自教师设计避免引入外部模型，保持策略一致性，且训练后无额外推理成本；令牌级优势与GRPO融合自然，实现粗细粒度监督互补。
- **实验亮点**：全面的消融实验和系数敏感性分析；交互效率对比证明GAPD不仅准确高且更高效；案例研究直观展示令牌级指导的具体效果。
- **性能优势**：在三个标准KBQA基准上均大幅度超越先前最佳方法，且使用8B开源模型即可超越商业闭源LLM（如Claude 4.6 Sonnet）。

## 8. 不足与局限

- **训练开销**：相比仅结果RL，训练时间约增加1.5倍（8.2h→12.4h）。尽管推理时更快，训练成本仍需权衡。
- **依赖黄金逻辑形式**：方法需要数据集提供黄金逻辑形式标注，限制了在无标注场景的适用性（实时标注或合成黄金动作可能作为替代，但论文未探索）。
- **实体锚点匹配阈值**：固定阈值 \(\tau_{\text{state}}=0.95\)，可能过于严格或宽松，未做更多敏感性分析。
- **骨干规模限制**：实验仅在Llama-3.1-8B上运行，未验证在更小或更大模型上的泛化能力。
- **泛化到其他任务**：方法聚焦KBQA，若将此蒸馏框架用于其他agentic RL任务（如Web代理、工具使用），需重新设计状态空间和锚点定义。
- **未在提升基线上应用**：如KnowCoder-A1使用不同训练策略，未尝试将GAPD作为其改进；仅与自身基线KBQA-R1对比，缺少对不同RL框架的融入验证。
