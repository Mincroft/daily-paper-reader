## 摘要
强化学习（RL）天然适用于智能体知识库问答（KBQA），其中模型必须执行可执行动作、观察知识库反馈并最终返回答案。然而，当前基于RL的KBQA系统主要优化来自最终答案的稀疏奖励，导致中间动作错误监督不足。这对于逻辑形式标注的KBQA基准尤其受限：黄金逻辑形式可转换为可执行动作序列，但现有流水线主要将其用于热启动数据构建，而非用于在线策略RL更新。我们提出GAPD，一种训练时的黄金动作策略蒸馏框架，它为基于结果的RL添加了密集的令牌级指导。为将黄金动作与在线策略学生轨迹对齐，GAPD使用中间锚点匹配：它将学生探索和黄金执行过程中达到的中间实体视为状态锚点，并通过这些探索到的实体集将学生状态与黄金状态匹配。针对对齐后的黄金动作的条件化当前策略作为停止梯度教师，其令牌分布被蒸馏回生成动作令牌跨度上的普通学生策略。GAPD在WebQSP、GrailQA和GraphQ上持续超越当前最先进水平。

## Abstract
Reinforcement learning (RL) is a natural fit for agentic knowledge base question answering (KBQA), where a model must issue executable actions, observe knowledge-base feedback, and eventually return an answer. However, current RL-based KBQA systems mainly optimize sparse rewards from the final answer, leaving intermediate action errors weakly supervised. This is especially limiting for logical-form annotated KBQA benchmarks: gold logical forms can be converted into executable action sequences, but existing pipelines use them mainly for warm-start data construction rather than for on-policy RL updates. We propose GAPD, a training-time Gold-Action Policy Distillation framework that adds dense token-level guidance to outcome-based RL. To align gold actions with on-policy student rollouts, GAPD uses MID-ANCHOR MATCHING: it treats the intermediate entities reached during student exploration and gold execution as state anchors, and matches student states to gold states through these explored entity sets. The current policy conditioned on this aligned gold action serves as a stop-gradient teacher, whose token distribution is distilled back to the ordinary student policy over generated action-token spans. GAPD consistently surpasses the current state of the art on WebQSP, GrailQA, and GraphQ.

## 2. 论文提出的方法论

### 核心思想
GAPD在基于结果奖励的RL基础上，增加基于黄金动作的令牌级蒸馏指导。核心在于：当学生策略在在线探索中到达某个中间状态时，先通过实体锚点匹配（Entity-Anchor Matching）将该状态与黄金执行路径中的某个状态对齐，然后利用对齐的黄金动作构建教师提示，将当前策略条件化得到自教师分布，再蒸馏回普通学生策略的生成令牌上。

### 关键技术细节
1. **黄金动作序列提取**：从黄金逻辑形式解析出动作序列 `g = (g1,...,gM)`，并预执行该序列以收集每个步骤的中间状态（可达实体集）。
2. **实体锚点匹配（Entity-Anchor Matching）**：对于学生第t步状态st，计算其可达实体集与所有黄金状态um可达实体集的Jaccard相似度，选择最匹配的黄金状态索引m*(t)。仅当相似度≥阈值0.95时接受匹配。
3. **自教师构建**：在学生当前上下文xt中加入对齐的黄金动作gm*(t)+1，形成教师提示xt~，将当前策略πθ在该提示下的分布（停止梯度）作为自教师分布pteach。
4. **令牌级优势计算**：对匹配的令牌跨度，计算教师与学生的对数概率差 d_i,k = log pteach(y_i,k) - log pstud(y_i,k)，裁剪后作为GAPD优势A_gapd。最终融合优势为: A_total = A_GRPO + λ_gapd * A_gapd。
5. **融合策略更新**：使用标准的GRPO风格PPO裁剪目标，但优势为令牌级融合优势。

## 7. 优点

- **创新性**：首次将黄金动作序列直接融入在线RL训练，通过实体锚点匹配实现状态对齐，解决了稀疏奖励信用分配问题。
- **高效性**：仅使用策略自身的自教师，无额外外部模型；训练开销合理（约1.5倍），测试时无额外成本且调用更少。
- **鲁棒性**：对超参数λ_gapd不敏感，实体锚点匹配阈值较高（0.95）确保对齐可靠性。
- **全面性**：在三个基准上验证，包含多维度消融、敏感性、交互效率分析，实验充分。
- **实用性**：动作空间有限（7种动作），利于实际部署；方法不依赖昂贵外部模型。

## 8. 不足与局限

- **训练成本**：相比仅结果奖励RL，训练时间增加约50%，对资源受限团队可能构成门槛。
- **依赖逻辑形式注释**：方法需要数据集提供黄金逻辑形式，不适用于仅有问答对的无标注场景。
- **动作空间固定**：当前动作空间为7种原子操作，可能无法处理需自由规划复杂查询的情况。
- **未见零样本泛化讨论**：实验仅评估了GrailQA的零样本子集（零样本泛化），但未深入分析新关系/实体未预见的泛化能力。
- **仅基于Llama-3.1-8B**：主实验仅使用一种骨干模型，未验证在其他规模或架构上的迁移性。
- **实体锚点匹配依赖Jaccard相似度**：对于实体集为空或极小的情况，匹配可能不准确；阈值0.95设定较为保守，可能丢失部分有用训练机会。
- **蒸馏仅在匹配turn生效**：对于无法匹配的turn（如首次动作就偏离），GAPD无法提供指导，可能影响早期学习效果。
