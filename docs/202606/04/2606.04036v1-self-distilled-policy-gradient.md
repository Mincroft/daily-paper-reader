## 摘要
在策略自蒸馏方法中，语言模型依据特权上下文监督自身生成，为稀疏奖励强化学习提供了有前景的密集监督来源。实际上，该方法可被实例化为一种辅助的全词汇学生到教师反向KL散度损失。为此，我们提出SDPG——一种自蒸馏策略梯度框架，它结合了组相对验证器优势、归一化标准差、精确的全词汇在策略自蒸馏以及参考策略KL正则化。实验表明，与RLVR及自蒸馏基线方法相比，SDPG在稳定性和性能上均有提升。代码已开源：https://github.com/lauyikfung/SDPG。

## Abstract
On-policy self-distillation, where a language model conditions on privileged context to supervise its own generations, is a promising source of dense supervision for sparse-reward reinforcement learning. Actually, it can be instantiated as an auxiliary full-vocabulary student-to-teacher reverse Kullback-Leibler divergence loss. We therefore propose SDPG, a self-distilled policy-gradient framework that combines group-relative verifier advantages with normalized standard deviation, exact full-vocabulary on-policy self-distillation, as well as reference-policy KL regularization. Empirically, SDPG improves stability and performance over RLVR and self-distillation baselines. The code is available at https://github.com/lauyikfung/SDPG.

# 论文详细总结：Self-Distilled Policy Gradient

## 1. 核心问题与整体含义

- **研究动机**：在大型语言模型的强化学习训练中，基于可验证奖励的方法虽然有效，但面临**稀疏奖励**问题——序列级奖励无法为每个token提供有效反馈。此外，传统在线自蒸馏方法（如OPCD、OPSD）虽有希望提供密集监督，但要么依赖外部教师模型造成内存负担，要么缺乏外部验证器导致训练不稳定或模式坍塌。
- **核心问题**：如何利用模型自身的特权上下文（如真实答案、推理路径）来产生密集、稳定的自监督信号，同时保留外部验证器的全局选择能力，从而提升稀疏奖励下的策略优化效果。
- **整体含义**：提出SDPG框架，将在线自蒸馏与组相对策略优化融合，实现“密集+稀疏”双重信号互补，显著提升数学推理任务的训练稳定性和最终性能。

## 2. 方法论

- **核心思想**：利用同一模型在学生模式（仅有问题）和教师模式（额外拥有正确答案等特权上下文）下的输出分布差异，通过反向KL散度实现全词汇在线自蒸馏，同时结合组相对验证器优势提供全局指导，并用参考策略KL正则化保持更新稳定性。
- **关键技术细节**：
  - **奖励部分**：继承GRPO的组相对优势，但对同一个prompt采样G个回答，计算归一化优势 \( A_{\text{out}}^{(i)} = (R^{(i)} - \mu_G) / (\sigma_G + \epsilon_{\text{std}}) \) ，使用REINFORCE风格损失（无裁剪）。
  - **自蒸馏部分**：对每个采样前缀，计算学生分布 \( p_t(a) = \pi_\theta(a|x, y_{<t}) \) 和特权教师分布 \( q_t(a) = \pi_\theta(a|c, x, y_{<t}) \) 之间的**全词汇反向KL散度** \( D_{\text{KL}}(p_t \| \bar{q}_t) \) 。其中教师分支停止梯度。该损失等价于一个具有中心化日志比优势的策略梯度形式（Proposition 3.1）。
  - **正优势门控**：仅对组内优势为正的轨迹（\( A_{\text{out}} > 0 \)）施加蒸馏损失，避免在错误轨迹上强化局部合理但全局错误的token。
  - **β调度器**：蒸馏系数采用**热身-衰减**调度，初期线性增加使蒸馏信号逐步生效，后期线性衰减以避免教师信号过度约束学生探索。
  - **参考策略KL正则化**：使用**非归一化KL散度（UKL）**，包括前向（UFKL）和反向（URKL）两种变体。推导出对应的可微分替代损失（如对于URKL：\( \frac{1}{2} \log^2(\pi_\theta / \pi_{\text{ref}}) \) ），避免标准KL期望梯度偏差。
- **算法流程**：每步采样一批prompt → 使用当前策略采样G个回答 → 计算组内优势 → 对每个token计算学生和教师分布 → 累积全词汇KL蒸馏损失（仅在正优势轨迹上） → 加上UKL正则化 → 整体最小化 \( L_{\text{SDPG}} = L_{\text{out}} + \beta L_{\text{OPD}}^+ + \alpha L_K \) 。
- **公式要点**：\( L_{\text{OPD},t} = D_{\text{KL}}(p_t \| SG[q_t]) = \sum_{a} p_t(a) \log \frac{p_t(a)}{SG[q_t(a)]} \) ；UFKL及URKL的替代损失可由文中推导得到。

## 3. 实验设计

  - 评估：AIME2024、AIME2025、AMC23（均为数学竞赛）。
- **基准方法**：GRPO（Shao et al., 2024）、RLSD（Yang et al., 2026a，自蒸馏结合GRPO）、OPCD（Ye et al., 2026，纯在线自蒸馏）。
- **实验场景**：

## 6. 主要结论与发现

- SDPG（尤其是UFKL变体）在AIME24/25和AMC23上**全面优于**GRPO和RLSD，最终准确率和峰值准确率均为最高。
- 训练动态显示：SDPG的奖励上升更快，且保持更高的动作熵（RLSD熵快速塌陷至0），表明更强的探索能力。
- 正优势门控+β调度有效防止蒸馏信号干扰，且衰减阶段释放学生模型，避免过度约束。
- 消融证实：OPD蒸馏提供快速收敛，KL正则化稳定更新防止模式坍塌，二者缺一不可。
- 在更小的1.7B模型上，纯自蒸馏基线OPCD出现训练崩溃（准确率骤降，响应长度缩短），而SDPG保持稳定，体现鲁棒性。
