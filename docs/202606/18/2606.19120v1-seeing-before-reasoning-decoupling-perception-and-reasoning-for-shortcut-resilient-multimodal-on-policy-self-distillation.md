## 摘要
在策略自蒸馏（OPSD）在模型自身的展开上训练模型，并使用冻结副本提供基于参考目标的密集token级目标。这在大语言模型推理中效果良好，但直接扩展到多模态大语言模型（MLLMs）可能产生捷径：特权目标可能主要基于文本参考目标而非图像指导token。我们提出ViGOS，一种用于MLLM后训练的视觉引导OPSD框架。学生首先撰写视觉描述，然后推理最终答案。对于有效展开，仅图像的感知教师监督描述，而特权推理教师在相同学生前缀上监督推理和最终答案。仅对无效展开使用参考教师以恢复输出格式。在通用视觉语言、专家推理、视觉数学、空间定位和视觉语言先验基准测试中，ViGOS保持了OPSD的主要优势，并在易出现捷径的设置中改进了基于图像的行为。

## Abstract
On-policy self-distillation (OPSD) trains a model on its own rollouts and uses a frozen copy to provide dense token-level targets conditioned on a reference target. This works well for LLM reasoning, but a direct extension to multimodal large language models (MLLMs) can create a shortcut: the privileged target may guide tokens mainly based on the text reference target rather than the image. We propose ViGOS, a visually grounded OPSD framework for MLLM post-training. The student first writes a visual description and then reasons toward the final answer. For valid rollouts, an image-only perception teacher supervises the description, while a privileged reasoning teacher supervises the reasoning and final answer on the same student prefix. A reference teacher is used only for invalid rollouts to recover the output format. Across general vision-language, expert reasoning, visual math, spatial grounding, and visual-language-prior benchmarks, ViGOS keeps the main benefits of OPSD and improves image-grounded behavior in shortcut-prone settings.

## 1. 论文的核心问题与整体含义（研究动机和背景）

- **研究动机**：将文本领域的在策略自蒸馏（On-Policy Self-Distillation，OPSD）直接扩展到多模态大语言模型（MLLMs）时，会出现严重的**捷径（shortcut）问题**。在OPSD中，教师模型可以访问参考答案 `a⋆`，因此在为学生的每个token提供密集监督时，可能主要依赖文本答案而非图像内容。这导致学生学会产生与答案一致但视觉证据薄弱的推理，即“语言先验”或“答案驱动”的捷径。
- **核心问题**：如何让多模态自蒸馏既能保留答案引导推理的优势，又能强制模型在推理前先进行可靠的视觉感知？
- **整体含义**：本文提出了**ViGOS**（Visual Grounding On-Policy Self-Distillation）框架，通过解耦感知与推理阶段，将图像-文本的依赖关系结构化为“先看后思”的流程，从而在保持OPSD收益的同时显著增强模型对图像的真实利用。

## 2. 论文提出的方法论

### 核心思想
- 学生采样结构化的响应序列：`y = (d, r, a)`，其中 `d` 是视觉描述，`r` 是推理过程，`a` 是最终答案。输出格式为 `<description>d</description><think>r</think>\boxed{a}`。
- 对每个token，根据其所属的段，使用**不同的教师**提供监督信号，从根本上隔离参考答案对视觉描述部分的影响。

### 关键技术细节
1. **三个教师角色**（均来自冻结的初始MLLM副本，参数不更新）：
   - **图像感知教师（image-only perception teacher）**：仅以图像 `I` 作为外部上下文（不含问题、答案选项或参考答案），监督描述段 `Td` 的每个token，损失为反向KL散度：`Lperc = E[ (1-minv) Σ DKL(q_img,t ∥ p_θ,t) ]`。
   - **特权推理教师（privileged reasoning teacher）**：以图像 `I`、问题 `x` 和参考答案 `a⋆` 作为上下文，监督推理段 `Tr` 和答案段 `Ta` 的每个token，损失为 `Lrea = E[ (1-minv) Σ DKL(q_rea,t ∥ p_θ,t) ]`。
   - **参考教师（reference teacher）**：仅在输出格式无效（如缺少分隔符、描述或推理为空）时激活，使用完整上下文（`I, x, a⋆`）监督整个轨迹，但采用反向KL形式 `Lref = E[ minv Σ DKL(p_θ,t ∥ q_ref,t) ]`，作为格式恢复信号。
2. **有效/无效展开判断**：`minv(y)=1` 当且仅当输出格式不满足要求（即使答案错误但格式正确仍视为有效）。
3. **总体损失**：`LViGOS = λperc Lperc + λrea Lrea + λref Lref`。每个活跃KL和均按监督token数归一化。

### 算法流程（文字说明）
- **阶段1：结构化在策略展开**：学生在给定图像和问题下，使用格式化提示采样一条轨迹 `y = (d, r, a)`。
- **阶段2：段解析**：解析 `y` 得到描述token集 `Td`、推理token集 `Tr`、答案token集 `Ta` 以及无效标记 `minv`。
- **阶段3：分段教师监督**：
  - 若有效：描述token由图像感知教师监督，推理+答案token由特权推理教师监督；
  - 若无效：所有token由参考教师监督（反向KL）。
- 推理时：只使用学生模型，无需任何教师。

## 6. 论文的主要结论与发现

- **ViGOS保持OPSD主要收益**：在8个标准基准上，ViGOS的Pass@5和Avg@5与OPSD相当或略优，显著超过基线。
- **ViGOS显著改善先验冲突场景**：在ViLP上，ViGOS在Score上大幅优于OPSD和基线，同时Prior几乎不降（保持在>97%）。例如7B模型上ViGOS的ViLP-F Score从基线的42.00%提升至62.67%，而OPSD为58.00%。
- **解耦感知与推理是关键**：PALR诊断显示，ViGOS在推理-答案段的答案驱动监督比例从OPSD的17.26%降至6.33%（3B），26.01%降至7.56%（7B），表明参考答案的直接影响被有效限制。
- **三个教师组件均必要**：消融移除任一损失都会导致性能下降（特别是在ViLP上），参考教师作为格式恢复信号不可或缺。
- **同提示控制实验**进一步证实收益来自监督分离而非仅仅结构化提示。
